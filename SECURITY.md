# Security Policy

## Supported Versions

Please ensure you are using the latest version of the extension. We only provide security updates for the latest major release.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please **DO NOT** report security vulnerabilities via public GitHub issues. 

Instead, please report them by using the **Private Vulnerability Reporting** feature in the GitHub Security tab.
